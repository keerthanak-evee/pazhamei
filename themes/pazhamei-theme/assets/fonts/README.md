# Fonts

Self-hosted variable fonts, downloaded once from Google Fonts (latin subset, Tamil subset for Noto Sans Tamil).
All four are licensed under the SIL Open Font License 1.1, which allows bundling them in a theme.

| File | Family | Used for |
|---|---|---|
| `plus-jakarta-sans*.woff2` | Plus Jakarta Sans | Body text and buttons |
| `cormorant-garamond*.woff2` | Cormorant Garamond | Headings |
| `cinzel.woff2` | Cinzel | Logo and site title |
| `noto-sans-tamil.woff2` | Noto Sans Tamil | Tamil text |
